# Допущения и решения

Сюда записываются решения, принятые без полной информации, и их обоснование. Если допущение
подтвердилось или опровергнуто — пометьте это здесь, а не удаляйте запись.

Статусы: **принято** — решение действует; **проверить** — нужна сверка с источником или прогоном;
**подтверждено** — проверено, указано чем.

Нормативный контракт API — [API.md](API.md) 1.0.0 (разделы указаны в скобках; отличия от rc2 — раздел 0);
рассмотренные варианты и обоснования его решений — [DECISIONS.md](DECISIONS.md).

Разделы: решения контракта (A-), основы (F-), семейств устройств (AI-, DI-, M-, VFD-, VLV-, CV-, P-),
открытые вопросы семейств (…-Q), интеграции (I-), платформа (P1…P5), исходники и сборка (B), проверено
во время выполнения (R, L), тесты (C), инструменты CODESYS (D).
